Microsoft Cloud Tech Day: Microsoft 365

By Raúl Bojalil • 2023-12-18

I was recently invited to a Microsoft Cloud Tech Day event at the Microsoft office in Mexico City. Here are my thoughts on it.

Surprisingly, this is my first time going to a Microsoft Tech Days event, so I didn't know what to expect. I've attended several Amazon Web Services events in the past, like the AWS Summit, so I had a vague idea of what to expect. But in the end I really enjoyed it, so keep reading to hear my thoughts.

The event was 4 hours long and it focused on the Microsoft 365 line of products. Most people (myself included, though not anymore!) think that Microsoft 365 is just the fancy new name for Microsoft Office. But Microsoft 365 is much more than that—it's a comprehensive suite of tools intended for increasing the security and productivity of organizations.

Microsoft Cloud

The first section of the presentation focused on the benefits of migrating to the cloud (like productivity gains and cost savings), the Fortune 500 companies that use Microsoft Azure (like Coca-Cola and BMW), and the powerful infrastructure located in more than 65 regions around the world that makes all of this possible. Most people think that Microsoft and Linux are "enemies," but that's far from the truth: roughly 50% of Azure VMs run Linux, and they also have co-located support with Red Hat.

You may already know that I'm a huge fan of GitHub, so another exciting detail I learned is that you can use GitHub to implement DevOps across an organization using the Microsoft Cloud Adoption and Microsoft Azure Well-Architected frameworks. These frameworks are designed to facilitate the implementation of Azure tools and best practices.

Microsoft 365

This was, of course, the main topic of the presentation. They focused on the two main strong points of Microsoft 365: productivity increases (by simplifying communication between employees and business partners) and organizational security. Before this, I had a lot of misconceptions about what you could and couldn't do with Microsoft 365.

Microsoft offers the following plans, each containing different applications and services:

  • Business Apps: Includes desktop apps like Outlook, Word, Excel, PowerPoint, Publisher, and Access.
  • Business Basic: Includes Teams, Exchange, OneDrive, and SharePoint.
  • Business Standard: Business Apps + Business Basic.
  • Business Premium: Business Standard + additional productivity tools (Bookings, Delve, Engage, Forms, Power Apps, Power Automate) and advanced security tools (Intune, Defender).

Aside from all these services, Microsoft includes baseline security features across all plans, such as data encryption, regulatory standards compliance, multi-factor authentication, and privacy controls.

Microsoft 365 Business Premium

Beyond the myriad of applications already included, the Business Premium subscription features security tools and capabilities intended to defend against threats and protect business data.

Some of the key security platforms showcased during the event included:

  • Microsoft Defender: An all-around cybersecurity platform providing protection against viruses, malware, and other threats. It features real-time threat detection, automatic cleanup, malicious software execution prevention, a network-monitoring firewall, and anti-phishing protection.
  • Microsoft Intune: Helps organizations manage and secure mobile devices, computers, and applications from a central location. It provides tools for device configuration, software deployment, and security policy enforcement, ensuring users only access required resources.
  • Microsoft Entra: A security and identity management platform enabling secure identity management across an entire digital estate. It automates identity governance and access management, reducing risk and complexity while improving productivity.
  • Microsoft Purview: A comprehensive data governance platform for managing data across all locations. It offers data discovery, classification, analytics, and policy enforcement tools. Notably, support for Mexican personal data protection laws is starting to be integrated.

Aside from these security services, Microsoft Loop was also showcased—a really cool way to collaborate on documents in real-time. They showed a demo of Loop combined with Teams, which significantly boosts remote team productivity. They promised a dedicated master class on Microsoft Loop, which I'm eagerly awaiting.

Microsoft Power Platform

Another platform highlighted was the Microsoft Power Platform, touted as the world's most complete set of integrated, low-code development tools.

Notable highlights include:

  • Power Apps: For developing low-code business apps (reminded me of working with Microsoft LightSwitch back in the day).
  • Power Virtual Agents (Copilot Studio): For quickly building AI chatbots.
  • Power Pages: A low-code way to build data-driven websites.
  • Power BI: A business intelligence platform for analytics and reporting.

The core goal of the Power Platform is to empower organizations to build applications as quickly as possible. Some developers fear tools like these might make them obsolete, but don't worry—developers are still very much needed!

Microsoft HoloLens & Hardware

At the end of the presentation, we had the opportunity to try out some of Microsoft's latest tech, such as the Microsoft HoloLens augmented reality glasses (if you know me, you already know I'm a big fan of AR and use it in my day-to-day work).

We also got to hands-on test the new Microsoft Surface lineup, which I loved as a fan of handheld and compact computers. All in all, Microsoft products cover a lot of ground in both enterprise and consumer spaces.

Overall, I really enjoyed the event, but I definitely need to attend the next Tech Day since they barely scratched the surface of what's possible with Microsoft 365. Here's hoping the next one is even better!
